Here are the basic rating standards for this server.

## Classic Levels
### Star Rate
* The Level should have at least 30 seconds long
* Layouts shouldn't have any presence of secret way

### Featured Rating
#### Layout Category
* Layout should have at least a minute of gameplay
* The layout must be fully structured to the point it looks like you're playing on one of those "Dear Nostalgists" bootlegs or those modern shitty levels
* Layouts with sugarcoated effects such as glow on some places are allowed
#### Decorated Category
* 50% the level should have a decoration
* Levels that have the intention to be old school type level have a chance to be featured, If there are modern features present such as red jump pad in a supposed 1.6 update styled level will lose its chance.

### Epic Rating
* The level must be fully decorated with a quality put into it, and a potential feature rating on official Geometry Dash server
* Level should have at least a minute of gameplay

### Legendary Rating
* The level shouldn't have any bugs present in the level
* Epic Rating applies

## Platformer Levels
This only affects decoration quality except some exceptions
### Star Rate
* Layouts belong to this group, This includes Hard Platformer Layouts

### Featured Rating
* The level must be entirely decorated

### Epic Rating
* Too good to be on this server

## Level Reuploads
* Levels that are reuploaded from main servers still apply to this GDPS Rating Standards
* The level has to be still entirely created by a Filipino
* Level has to be beaten on this GDPS for the level to become Rated and placed on Demonlist
