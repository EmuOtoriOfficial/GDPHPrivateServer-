There are multiple ways to reupload your levels from server to server with these basic tutorials, From your Personal Bulky Machine to your Brick.

# Android
There are "only" one method on reuploading levels

## Method 1: Geode
Remember to have your Geometry Dash purchased on Play Store and running Android 6 Marshmallow (or later) or else it will not work!

### Requirements
* [Geometry Dash](https://play.google.com/store/apps/details?id=com.robtopx.geometryjump&hl=en&gl=US)
* [Geode](http://geode-sdk.org/install/)
* Private Server on 2.205
* Geode GDPS Port
* Any file manager that you can see app icons inside Android folder (Such as ZArchiver, NMM, or FV File Explorer)

### Notes
* This tutorial will expect that you already have these 5 installed.
* If you don't have your Geode GDPS Port, You can create yourself one from this [YouTube Tutorial](https://www.youtube.com/watch?v=9XkxVwN6YuA&feature=youtu.be).
* If it appears that the Geode GDPS Port icon is unmodified, Just rely on a custom package name.

### Setup (Optional)
You don't have to do this over again if you already have your account logged into Geode and has more progress than the original one.
1. Backup your Geometry Dash Account
2. Open Geode and load your Geometry Dash data
3. Open your Geode GDPS Port and login your account from a GDPS

### Main Tutorial
1. Open a file manager
2. Go to this destination: `Internal Storage/Android/media/com.geode.launcher/saves/`
3. Copy CCLocalLevels.dat
4. Paste it to `Internal Storage/Android/media/(geode with gdps custom package name)/saves`
5. Open your Geode GDPS Port and start uploading your levels

# Windows
## Method 1: The Traditional Way
Basic tutorial on how to reupload a level you've saved, this requires a verified level that hasn't been uploaded to the servers. Works on Every Version.
1. Open "Run" by pressing "Windows + R"
1. Type "%localappdata%" and click "Ok"
1. Go to "GD Philippines" folder then backup "CCLocalLevels.dat"
1. After that, Go to "GeometryDash" folder and find "CCLocalLevels.dat"
1. Copy that and paste it to "GD Philippines" folder
1. Open the game, and upload the level you'd wanted to upload.

This same procedure can be also done in opposite folders by doing the same steps provided except you have to use the “GeometryDash” folder instead on step 3, “GD Philippines” on step 4, and “GeometryDash” on step 5. 

## Method 2: Using GDShare
1. Install Geode to your GDPS
1. Install "GDShare" on Geode Index
1. Open up Geometry Dash and export a level you wanted to reupload
1. Import and reupload

4. Move GDShare.dll to:
- For MHv7: the extensions folder
- For GD HackerMode: the GDHM/dll folder
- For quickldr: the quickldr folder & write GDShare-v0.3.4.dll to settings.txt
5. Move the .pngs in resources to GDPH resources (you will also install this on original GD)
6. Open the game, go to your saved levels and find what you want to reupload. Find the button to the left and click, select .gmd and hit export.
7. After, Open GDPhilippines.exe, go to your created levels and locate a similar button below the right.
8. Click and find where you previously saved the exported .gmd file and select it, it will appear on your created levels. Having a custom file directory to save exports works best

# 2.1 Android
### Requirements
* Unuploaded Verified level
* IAD Mod Menu or MegaHack Mobile

### Data Backup
1. Open "GD Philippines"
1. Go to "Utilities"
1. Tap "Backup"
1. Go to file manager
1. Find "GDPH" folder and open
1. Open "saves" folder
1. Backup your "CCLocalLevels.dat" that was used on GDPH to the other folder you'd wanted to put (Remember where you put it)

### Importing Save File
**IAD Mod Menu Users**
1. Open Geometry Dash
1. Open the mod menu
1. Scroll down until you see "Save Manager"
1. Tap "Backup Locally"
1. After the backup, Go to File Manager
1. Go to "GDmods/saves"
1. Copy/Move "CCLocalLevels.dat" to "GDPH/saves"

**MegaHack Mobile Users**
1. Go to file manager
1. Find "MegaHackMobile" folder and open
1. Open "gamesaves" folder
1. Copy "CCLocalLevels.dat" to "GDPH/saves"

### Loading the data and upload
1. Open "GD Philippines"
1. Open "Utilities"
1. Tap "Load"
1. After you tap load, Restart the game
1. Upload levels you'd wanted to reupload

### Loading GDPH Data Backup
1. After you're done uploading the level, Here are few steps to restore your Local Created levels
1. Find "CCLocalLevels.dat" you backup
1. Copy/Move to "GDPH/Saves" and overwrite it
1. Open "GD Philippines"
1. Open "Utilities"
1. Tap "Load"
1. After you tap load, Restart the game
1. There you go, It's done.
