# Geode Mods Private Server Compatibility List
Not all of the mods have been tested

a list of mods that are compatible with private servers. mods that are partially working/requires workaround, and simply not working are listed here:

## Working Mods
Runs the mod with no problems at all as most of it are just client-sided
1. **Level Info**
1. **QOLMod**
1. **Texture Loader**
1. **Run Info**
1. **BetterEdit**
1. **A daily shop**
1. **Advanced Song Search**
1. **BetterPause**

## Mods requires workaround
This Requires Workaround to make it work
1. **Globed** - Requires custom server files to host

## Mods that are not made for Private Servers
Mods that do work except it simply doesn't made for Private Servers
1. **Level Thumbnails** - Shows other people's levels

## Non-functional Mods
List of mods that are simply not working
1. **Better Progression** - Runs fine for a few seconds and crashes, Guessing that it attempts to fetch profiles(?) from official GD servers except it doesn't work since it connected to a private server. (Can be found on src/Request.cpp on BetterProgression github page)
1. `Android` **GDShare** - Attempting to import a level sends you to actual Geode file permission page instead of modified one
